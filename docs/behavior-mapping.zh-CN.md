# 自主行为映射

内部状态 → 动作决策映射，仅限驱动力层（身体）。

**注意**: 此系统没有评估或规划能力。以下映射完全是机械式的 — 激素水平影响欲望增长，欲望按强度竞争，最强胜出决定动作。

## 概览

```
激素 → 调制 → 欲望 → 竞争 → 最强胜出 → 动作 → 反馈 → 激素
```

无外部输入，无 LLM，无奖励函数。智能体行动因为其内部状态驱使它行动。

---

## 激素动力学

4 种激素独立振荡，通过正弦波 + 指数衰减 + 合成。

| 激素 | 基线 | 半衰期 | 振幅 | 周期 | 合成速率 | 作用 |
|------|------|--------|------|------|---------|------|
| 多巴胺 | 0.5 | 12 | 0.30 | 24 | 0.020 | 奖励/预期 |
| 血清素 | 0.6 | 20 | 0.15 | 40 | 0.010 | 满足/稳定 |
| 催产素 | 0.3 | 30 | 0.25 | 60 | 0.005 | 信任/联结 |
| 皮质醇 | 0.2 | 8 | 0.35 | 24 | 0.030 | 压力/唤醒 |

每个 tick 的更新公式:
```
衰减 = 0.5^(1/半衰期)
振荡 = 振幅 * sin(2π * tick / 周期)
目标 = 基线 + 振荡
衰减后 = 当前值 * 衰减
增量 = 合成速率 * sign(目标 - 衰减后) * min(|目标 - 衰减后|, 0.1)
新值 = clamp(衰减后 + 增量, 0, 1)
```

## 欲望动力学

5 种欲望具有内在增长和激素调制。

| 欲望 | 增长/tick | 满足后衰减 | 激素调制 |
|------|-----------|-----------|---------|
| 探索 | +0.020 | ×0.50 | 无 |
| 社交 | +0.015 | ×0.40 | 无 |
| 饥饿 | +0.025 | ×0.60 | 无 |
| 休息 | +0.018 | ×0.55 | +皮质醇 × 0.3 |
| 精通 | +0.012 | ×0.35 | 无 |

每个 tick 的更新:
```
强度 = min(1, 强度 + 增长率)
如果为休息: 强度 = min(1, 强度 + 皮质醇 * 0.3)
```

满足公式 (当动作执行后):
```
强度 = max(0, 强度 * (1 - 衰减率) + 随机(0, 0.05))
```

## 动作选择

1. `getStrongest()` — 选出强度最高的欲望
2. 按 `satisfies` 数组过滤动作
3. 从候选动作中随机选择 (保证多样性)

| 欲望 | 候选动作 |
|------|---------|
| 探索 | explore |
| 社交 | socialize |
| 饥饿 | forage |
| 休息 | rest |
| 精通 | practice |

## 动作 → 反馈

| 动作 | 满足的欲望 | 激素效果 |
|------|-----------|---------|
| explore | 探索 | 多巴胺 +0.08，皮质醇 +0.03 |
| socialize | 社交 | 催产素 +0.12，血清素 +0.05 |
| forage | 饥饿 | 多巴胺 +0.10，血清素 +0.04 |
| rest | 休息 | 皮质醇 -0.15，血清素 +0.06 |
| practice | 精通 | 多巴胺 +0.06，皮质醇 +0.08 |

反馈公式:
```
欲望.强度 *= (1 - 欲望.衰减率)     // 满足
激素.水平 += 激素效果                // 激素更新
激素.水平 = clamp(激素.水平, 0, 1)
```

## 涌现行为模式

由于欲望持续增长且只能被部分满足（满足后残留 ×0.4–0.65），多个欲望同时保持活跃。随着满足和激素反馈改变内部状态，最强欲望不断变化。

从 60 个 tick 的运行中观察到的模式:
- **动作切换** — 智能体几乎每个 tick 都切换动作 (59/60)
- **均匀分布** — 动作分散在 15–25% 之间，没有单一动作占主导
- **激素漂移** — 多巴胺/血清素/催产素随时间上升（增长 > 衰减），皮质醇保持低位（休息重置它）
- **自我调节** — 当皮质醇升高时（来自探索/练习），休息通过皮质醇增益变得更有吸引力，自然地将系统拉回平衡
